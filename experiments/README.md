# 실험 설정과 재현

현재 실험 미실행입니다. 실험마다 exp-001처럼 고유 ID를 부여합니다.

실험 기록:
- 연구 질문, 비교/고정 조건
- 데이터 버전과 code commit
- 정확한 모델 ID, provider, prompt 버전, seed 등 적용 가능한 설정
- 실행 명령, Python 및 의존성 버전
- 사례·조건·반복 수, 최대 호출 수, token/금액 상한
- 성공 판정, 오류·재시도·중단 정책
- 시작/종료 시각, 전체 시도 수와 결과 위치

실행 승인이 있기 전에는 API 호출하지 않습니다.
