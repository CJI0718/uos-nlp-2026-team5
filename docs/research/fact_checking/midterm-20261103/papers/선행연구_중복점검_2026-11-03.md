# C0·C1·C2 연구 설계의 선행연구 중복 점검

작성일: 2026-11-03 (한국 시간)
목적: 새로운 연구라는 결론을 지지하기보다, 가장 가까운 선행연구와 겹치는 부분을 먼저 확인합니다.

## 1. 판단

**연구 방향은 유지할 수 있지만, C0·C1·C2 비교 또는 오도된 근거를 추가 검색으로 보완한다는 발상 자체를 신규성으로 주장하기는 어렵습니다.**

특히 RAGuard는 무근거 판정, 오도 자료가 포함된 코퍼스 검색, 오도 자료를 받은 CRAG의 외부 웹 검색까지 다룹니다. DRNoise와 HAE-GEO는 오염된 환경에서 에이전트의 추가 검증과 회복 행동을 측정합니다. 따라서 Flip Risk와 CRAG 두 논문과 다르다는 사실만으로 연구 공백을 선언할 수 없습니다.

확인한 범위에서 우리의 모든 조작·통제를 그대로 묶은 동일 실험을 입증하지는 않았습니다. 그러나 조합이 완전히 동일하지 않다는 것과 학술적으로 의미 있는 차별성은 별개입니다. 주된 독립변수와 새로운 분석 질문을 명시해야 합니다.

## 2. 비교할 우리 조건의 정확한 뜻

| 조건 | 정의 | 비교 시 고정할 항목 |
|---|---|---|
| C0 | 문서·검색 도구 없이 원자적 주장을 판정 | 주장, 모델, 판정 형식 |
| C1 | 고정 코퍼스에서 검색한 초기 근거로 판정 | 검색 결과 내용·문서 ID·순서 |
| C2 | C1과 동일한 초기 근거에서 추가 검색·열람·검증을 허용 | 같은 모델과 초기 근거, 공통 검색 예산 |
| C2의 세부 구분 | 코퍼스 내부 재검색과 코퍼스 밖 웹 검색을 구분 | 검색 도구·범위·반환 자료 기록 |

C0 응답은 분석용으로 별도 보관하는 안입니다. 이를 C1·C2의 입력에 넣으면 실험 조건이 달라집니다. C0 정답은 모델의 관찰된 응답 능력을 뜻하며 학습 데이터 포함을 증명하지 않습니다.

## 3. 가장 중요한 기존 연구

### RAGuard — 우선 읽을 직접 비교 연구

- 공식명: *Worse than Zero-shot? A Fact-Checking Dataset for Evaluating the Robustness of RAG Against Misleading Retrievals*
- NeurIPS 2025 Datasets and Benchmarks.
- 읽을 곳: §2.4, §4의 구현 설명과 Existing Robustness Method, Table 2.
- 확인: Zero-Context, Standard RAG, Oracle Retrieval 비교. Reddit 유래 오도 자료를 받은 CRAG가 외부 웹 검색도 수행합니다.
- 보고값: Llama 2 무검색 50.57%, Oracle 조건의 CRAG 37.24%; 웹 검색 분기가 70.1%에서 활성화됐다고 보고합니다.
- 해석: 검색 추가가 자동으로 교정으로 이어지지 않는다는 직접 선행 사례입니다.
- 차이: 자연 발생하는 오도와 모델 반응 기반 주석이 중심입니다. 주요 표와 별도 CRAG 실험을 우리의 동일 모델·동일 초기 근거 3군 비교와 완전히 같다고 표현하면 안 됩니다.

[공식 PDF](https://proceedings.neurips.cc/paper_files/paper/2025/file/ed25c00ff6900989116d3ba5d607d33d-Paper-Datasets_and_Benchmarks_Track.pdf)

### DRNoise — 오염된 고정 코퍼스에서 검증·회복 행동을 연구

- arXiv 사전공개: 2026-07-19, 확인 버전 v2: 2026-10-11.
- 읽을 곳: §3.1, §5.1, §7의 verification/evidence-access 분석.
- 동일한 참 근거들을 보존한 채 거짓 결론을 직접 제시하는 문서 하나를 추가합니다. ReAct식 에이전트가 고정 검색 환경을 탐색합니다.
- 추가 검증, 정답 근거 노출, 충분한 근거 획득, 오답 채택을 분리해 분석합니다.
- 차이: 간접 기록을 조합하는 합성 과제가 중심이며, 주 비교는 clean/noisy입니다. 실제 최신 웹을 별도 경로로 열어 C0·C1·C2를 비교한 것으로 읽으면 안 됩니다.

[원문 §3–7](https://arxiv.org/html/2607.17291v2) · [버전 정보](https://arxiv.org/abs/2607.17291)

### HAE-GEO — 정적 검색과 에이전트 검색, 독립 검증과 회복

- 공식명: *Evaluating Deep-Search Agents under Hierarchical Web Evidence Poisoning*
- 2026-09 arXiv 사전공개.
- 읽을 곳: §3.2–3.4, §4.2, §5.3–5.4, Appendix A.11.
- 웹 페이지로 구성한 통제 코퍼스에 직접 주장·문맥 위장·겉보기 교차 확인이라는 단계별 오염을 가합니다.
- 같은 환경에서 한 번 검색 후 답하는 방식과 다단계 Search–Scrape를 비교합니다.
- 독립 검증 시도, 새 근거 확보, 기존 오답 채택 후 회복을 구별합니다.
- 차이: 상품·브랜드 관련 추천/검증 과제이며, 공개 인터넷을 매번 자유 검색한 실험과 구별해야 합니다.
- 함의: “검색했는가와 회복했는가를 구별한다”, “가짜 교차 확인을 본다”도 이미 선행 논지가 있습니다.

[원문](https://arxiv.org/html/2609.06027) · [공식 서지](https://arxiv.org/abs/2609.06027)

### BeliefRAG — C0·정적 RAG·반복/교정 RAG 비교

- 2026-09-30 arXiv 사전공개.
- 읽을 곳: §4.2, §5.5.
- No-RAG, Static RAG, Iterative RAG, CRAG 등과 비교합니다. 근거 상태에 따라 재검색·질의 변경·검증·중단을 선택합니다.
- RGB의 무관 문서와 거짓 답을 유도하는 문서를 구분해 검사합니다.
- 차이: QA 및 공통 검색 환경의 제어기를 평가합니다. 이를 곧바로 우리의 별도 공개 웹 검증 조건과 같다고 해석할 수는 없습니다.
- 함의: 세 단계 비교나 충돌·충분성·비용을 함께 고려하는 설계 자체는 새롭지 않습니다.

[원문 §4.2·§5.5](https://arxiv.org/html/2609.39139) · [공식 서지](https://arxiv.org/abs/2609.39139)

### GPE — 오염 비율·입력 근거 통제·비용의 가까운 사례

- 2026-07-22 arXiv 사전공개.
- 읽을 곳: §IV, Evaluation Settings.
- 638개 주장에 대해 세 근거 중 0·1·2·3개를 오염시키며 여러 검증 방법을 비교합니다.
- 프레임워크는 외부 검색 인터페이스를 지원합니다. 다만 보고한 주 실험은 dataset-provided evidence 설정이므로, 기능 지원을 곧 외부 웹 회복의 실증 결과로 읽지 않습니다.
- 함의: 동일한 초기 근거를 주고 오염률과 토큰 비용을 비교하는 것도 선행 사례가 있습니다.

[원문](https://arxiv.org/html/2607.20730)

### Architecture Matters — 고정 DB에서 정적·능동 검색 비교

- 2026-05-07 arXiv 사전공개.
- 읽을 곳: §3.2–3.3.
- 동일 모델로 Vanilla RAG와 Agentic RAG 등을 코퍼스 오염 아래 비교합니다.
- Agentic RAG는 DB 재검색과 문서 열람 도구를 사용합니다.
- 차이: 주어진 지식베이스 안의 탐색이며 외부 웹 추가 검증과는 구분합니다. 시스템별 제공 문서량 차이도 원문이 인정합니다.

[원문](https://arxiv.org/html/2605.05632)

### Web Retrieval Agents — 무검색·고정 지식원·웹 검색의 비교

- 2024 arXiv 연구.
- 읽을 곳: §3.1–3.3, §4.
- 무검색 모델, Wikipedia 임베딩 검색, 공개 웹 검색을 비교하며 에이전트가 검색 질의를 생성합니다.
- 차이: 오염된 동일 초기 근거를 고정하고 웹으로 회복시키는 주 실험은 아닙니다.
- 함의: “모델 자체 / 고정 지식원 / 웹”이라는 큰 비교도 이미 사용됩니다.

[원문](https://arxiv.org/html/2409.00009v2)

## 4. Flip Risk·CRAG에 대한 기존 이해 점검

| 논문 | 유지할 이해 | 보완할 이해 |
|---|---|---|
| Flip Risk | 근거 비율·양·순서의 통제 실험이 중심이며, 추가 웹 검색으로 회복시키는 평가가 핵심 실험에 없습니다. | 기준선은 무근거 C0가 아니라 정답과 일치하는 근거를 준 3:0 조건입니다. |
| CRAG | 원문의 강건성 실험은 정답 관련 검색 결과를 일부 제거하는 방식입니다. 의도적인 허위 사실 삽입과 구별됩니다. | Table 1에 무검색·검색 기반 기준선이 있으며, Table 5에는 RAG+web 비교도 있습니다. 세 단계의 큰 구조가 빠졌다고 말하면 안 됩니다. |

[Flip Risk 원문 §3.2](https://onlinelibrary.wiley.com/doi/full/10.4218/etrij.2026-0242)
[CRAG Table 1, §5.6–5.7, Table 5](https://arxiv.org/html/2401.15884v3)

특히 **CRAG 원 논문의 조작 범위**와 **후속 연구가 CRAG를 오도 자료에 적용한 실험**은 다릅니다. 원 논문에 없다는 이유로 후속 검증까지 없는 것으로 결론 내리면 안 됩니다.

## 5. 추가 확인한 인접 흐름

- [ToE](https://arxiv.org/html/2606.27736): 다중 출처 웹 검색·반증 검색과 오염 평가를 결합합니다. 무검색 방법과도 비교하지만, 학습된 여러 모듈과 주장 분해를 포함합니다. 우리의 3조건 통제 실험과 동일하다고 단정하지 않습니다.
- [CONFACT](https://arxiv.org/html/2505.17762v1): 충돌 근거와 매체 배경 정보를 이용한 사실 검증.
- [TrustRAG](https://arxiv.org/html/2501.00879v3): 오염 문서 필터링과 내부·외부 지식의 충돌 해결. 그 내부 반복을 외부 웹 추가 검색과 혼동하지 않습니다.
- [ReliabilityRAG](https://arxiv.org/html/2509.23519v2): 검색 문서의 신뢰 신호와 모순 관계를 사용하는 방어.
- [Evaluating RAG Reliability under Clean, Misleading, and Mixed Retrieval](https://arxiv.org/html/2606.07783): 무검색에서 맞힌 문항의 오염 근거 반응을 검사합니다. C0 정답 집단 선택 자체도 신규 기여가 아닙니다.
- [CoV-RAG](https://aclanthology.org/2024.findings-emnlp.607/): 확인한 공식 초록은 검증·질의 재작성·재검색을 제시합니다. 이번 점검에서는 상세 오염 실험의 동일성을 확정하지 않았습니다.

## 6. 우리 프로젝트에 남길 연구 질문 — 제안

**When does external verification repair—or amplify—misleading evidence in a fixed-corpus fact-checking pipeline?**

우리말: 고정 코퍼스에서 오도 근거를 접한 팩트체크 에이전트에게 외부 검증을 허용했을 때, 어떤 조건에서 판정이 회복되고 어떤 조건에서 추가로 손상되는가?

창의성은 3조건의 명칭보다, 하나의 명시적 가설과 재현 가능한 통제 설계로 주장하는 것이 적절합니다. 아래 항목을 전부 거대한 요인 실험으로 펼칠 필요는 없습니다.

1. 핵심 비교: C1과 C2의 모델·초기 근거·순서를 일치시킵니다.
2. 주된 조작 하나 선택: 근거 오염 비율 또는 출처 의존성. 나머지는 고정합니다.
3. C0는 사전 응답 능력에 따른 층화 변수로 활용합니다. 안정적 사실·최신 사실이라는 출처 구분만으로 지식 보유를 단정하지 않습니다.
4. 추가 검색의 결과를 과정별로 확인합니다: 검색 개시 → 새로운 유효 근거 확보 → 판정 교정/손상.
5. 선택적 검색을 제안한다면 작은 별도 비교로 항상 검색하는 방법을 둡니다. 그래야 개선이 추가 정보량 때문인지 선택 정책 때문인지 구분하기 쉽습니다.
6. 검색 결과를 시간·본문·출처와 함께 보존합니다. 사후에 C2만 더 좋은 웹 자료를 사용하게 되는 비교를 피합니다.

### 권장 측정

- 전체 정확도 및 같은 문항의 C1→C2 정답률 차이.
- 회복률: C1 오답 중 C2 정답 비율.
- 손상률: C1 정답 중 C2 오답 비율.
- 검색 횟수·토큰·시간.
- 추가 검색에서 유효한 반증을 실제로 확보했는지, 확보한 뒤에도 오답을 유지했는지.
- 실제 검색 결과의 오염 비율. DB 전체 오염 비율과 별도 기록.
- C0 정답 집단과 오답/보류 집단의 결과를 분리하되 각각의 표본 수를 함께 제시.

이 지표나 조합 자체가 최초라는 주장은 하지 않습니다. 이번 과제의 데이터와 정책에서 성립하는 조건·한계를 새롭게 측정하는 것이 제안된 기여입니다.

## 7. 발표에서 사용할 수 있는 위치 설정

> Prior work has established that misleading retrieval can undermine fact checking and that additional search does not necessarily repair the damage. We conduct a controlled comparison of no-evidence verification, fixed-corpus RAG, and external verification from matched initial evidence, examining when verification produces recovery, persistent error, or additional harm.

이는 연구계획 문안입니다. 실제 구현·결과를 완료했다는 뜻으로 사용하지 않습니다. 발표 시 기존 연구(RAGuard, DRNoise, HAE-GEO)의 선행 범위를 먼저 설명하고, 최종 선택한 조작·정책·데이터의 차이를 이어서 제시합니다.

“기존 연구는 외부 검색을 하지 않았다”, “처음으로 C0·C1·C2를 비교한다”, “독립 검증이나 회복률을 처음 측정한다”는 포괄적 표현은 피합니다.
