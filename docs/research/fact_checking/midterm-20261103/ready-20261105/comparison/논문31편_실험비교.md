# 31편 논문 실험 비교 · 발표 확인용

작성일: 2026-11-05 · NLP Team 5

연구가 바꾼 것, 모델이 본 정보, 성공을 세는 기준을 함께 비교합니다. D01–D31 원번호를 유지하며, RAG·ReAct·FEVER·Survey는 배경 묶음으로 분리합니다. 모델·데이터셋 목록은 각 행의 핵심 실험을 설명하는 대표 항목입니다.

연도 규칙: 논문명 뒤는 열람 판본의 학회/원고 연도입니다. 모델 뒤는 해당 계열·버전의 공개 연도, 데이터셋 뒤는 최초 공개 원고 또는 학회 연도입니다. 두 연도가 다르면 모두 표기합니다. 모델 공개 연도는 학습 cutoff가 아니며, 데이터셋 최초 공개 연도는 corpus snapshot 연도가 아닙니다. 체크포인트 최초 배포를 확정하지 못한 경우 기반 모델 연도라고 명시합니다.

행의 범위: 논문 전체를 한 가지 실험으로 축약하지 않도록 각 필드에 주요 조건과 역할을 적었습니다. 대표 수치는 같은 행의 모델·표본·조건에서 읽으며 논문 간 종합 순위를 뜻하지 않습니다. 원문 확인 위치와 PDF 링크로 해당 설정을 다시 확인할 수 있습니다.


## D01 · ClashEval · 2024 · NeurIPS

- **묶음**: 충돌
- **연구 질문·Task**: 기존 답과 외부 근거 중 어느 쪽을 따르는가? 사실 QA.
- **입력·평가 단위·정답 기준**: 질문 + 원본/변형 문서. 질문별 closed-book 응답과 최종 응답을 비교; 현실 정답 기준.
- **데이터셋·표본**: ClashEval (2024): 6개 분야, 1,294개 질문. 내용의 값·거리·문서 수를 조작.
- **주요 모델·역할**: GPT-4o (2024), GPT-3.5-Turbo-0125 (2024 snapshot; 계열 2023), Llama 3 Instruct (2024), Claude 3 Opus/Sonnet (2024), Gemini 1.5 Flash (2024).
- **검색·보조 모델**: 핵심 실험은 문서 직접 제공; 보정은 초기 응답 토큰 확률 활용.
- **검색 공간·방식**: 통제된 문맥 제공. 에이전트가 웹을 탐색하는 성능 시험과 구별.
- **행동·종료·예산**: 자료 없는 답 → 자료 있는 답. 검색 종료 정책은 연구 중심이 아님.
- **추가 학습**: 진단은 모델 고정; 별도 토큰 확률 기반 보정 실험.
- **근거 구성·실험 조작**: 정확한 문맥/잘못된 문맥, 초기 답의 정오, 사실 값의 변형 정도.
- **지표·분모**: Accuracy; Prior Bias = 문맥이 맞고 초기 답이 틀린 집합의 최종 오답률; Context Bias = 반대 집합의 최종 오답률.
- **대표 결과·조건**: Table 3, GPT-4o 보정 전후: accuracy .615→.754, prior bias .021→.085. 정확도 개선과 고집 증가가 공존.
- **해석 포인트**: 자료에 저항하는 능력과 올바른 자료로 교정되는 능력을 함께 읽어야 함. 모델 크기는 본문 표기 불일치가 있어 여기서는 계열명으로 표시.

## D02 · Adaptive Chameleon · 2024 · ICLR

- **묶음**: 충돌
- **연구 질문·Task**: 반대 근거의 구성에 따라 수용과 확증편향이 달라지는가?
- **입력·평가 단위·정답 기준**: QA를 기억 답/반대 답/Uncertain 선택형으로 변환; 관측된 초기 응답을 기억의 대리값으로 사용.
- **데이터셋·표본**: PopQA (2022 preprint/2023 학회), StrategyQA (2021). 모델별 기억 일관성·함의 검사 후 선별.
- **주요 모델·역할**: GPT-4 (2023), ChatGPT/GPT-3.5 계열 (2022 제품/2023 API), PaLM 2 (2023), Qwen-7B (2023), Llama 2 (2023).
- **검색·보조 모델**: DeBERTa-v2 MNLI 계열 (2021 기반 모델): 기억 passage의 함의 검사. 세부 checkpoint 배포일과 기반 모델 연도는 구별.
- **검색 공간·방식**: 생성한 기억 및 counter-memory를 직접 제공; 인터넷 검색 비교가 아님.
- **행동·종료·예산**: 한쪽 근거/양쪽 근거를 읽고 선택; 근거 수·순서·길이 비교.
- **추가 학습**: 주요 행동 진단은 모델 고정·프롬프팅.
- **근거 구성·실험 조작**: 단어 치환뿐 아니라 자연스럽고 일관된 반대 설명 생성; 기존 답 지지 근거와 경쟁.
- **지표·분모**: Memorization Ratio = 기억 답 선택 / (기억 답 + 반대 답 선택). Uncertain은 이 분모에서 제외.
- **대표 결과·조건**: 단독 반대 근거에는 수용적일 수 있으나, 양쪽 설명이 있으면 기존 답을 지지하는 자료를 선호하는 경향.
- **해석 포인트**: MR이 높다고 사실 정확도가 높다는 뜻은 아님. memory는 가중치에서 직접 추출한 지식이 아니라 응답·설명.
- **원문 확인 위치**: §3.1–3.6, §4.1–4.2
- **공식 원문**: https://arxiv.org/pdf/2305.13300v4
- **로컬 PDF**: https://arxiv.org/pdf/2305.13300v4

## D03 · Real Documents · 2024 · COLM

- **묶음**: 충돌
- **연구 질문·Task**: 처음 틀린 모델에게 실제 정답 문서를 주면 교정하는가?
- **입력·평가 단위·정답 기준**: 질문 → closed-book 오답 선별 → 원래 정답 passage 제공. 정답으로 수정/기존 오답 유지/다른 오답으로 수정.
- **데이터셋·표본**: MRQA 통합판 (2019): NQ (2019), SQuAD (2016), NewsQA·TriviaQA·SearchQA (각 2017), HotpotQA (2018). 모델마다 선별 집합이 다름.
- **주요 모델·역할**: Llama 2 7B/70B (2023), Mistral 7B (2023), Mixtral 8×7B (2023); 부록 GPT-3.5-Turbo (2023 계열).
- **검색·보조 모델**: BEM (2022): 답 동등성; NLI 모델: 충돌 사례 선별. NLI 세부 checkpoint는 원문 실험 상세 참조.
- **검색 공간·방식**: 정답을 포함하는 원래 passage를 직접 제공하는 simulated retrieval.
- **행동·종료·예산**: 문서 제공 전후 응답 비교; 추가 웹 검색 없음.
- **추가 학습**: 대상 LLM 추가 학습 없이 행동 분석; 학습된 평가 모델은 별도 역할.
- **근거 구성·실험 조작**: 외부 문서를 가짜로 바꾸기보다 초기 모델 응답이 틀린 사례를 선정.
- **지표·분모**: 정답 수정률/오답 유지율/다른 오답 수정률; 분모는 해당 모델의 선별된 초기 오답 사례.
- **대표 결과·조건**: Llama 2 7B, NQ: 정답 수정 79.6%, 유지 1.4%, 다른 오답 수정 19.0% (Table 3).
- **해석 포인트**: 79.6%는 전체 NQ 정확도나 실제 검색 성공률이 아님. 모든 모델에 동일한 실패 사례를 준 것도 아님.
- **원문 확인 위치**: §3.1–3.3, Tables 2–3

## D04 · Astute RAG · 2025 · ACL

- **묶음**: 충돌|제어
- **연구 질문·Task**: 내부 생성 passage와 검색 근거를 출처별로 통합하면 부실 RAG가 개선되는가?
- **입력·평가 단위·정답 기준**: 질문 + 외부 passages + 모델이 생성한 내부 passage → 답; QA 정답 기준.
- **데이터셋·표본**: NQ (2019), TriviaQA (2017), BioASQ (2013), PopQA (2022/2023), ASQA (2022), RGB (2023 preprint/2024 학회).
- **주요 모델·역할**: Claude 3.5 Sonnet-20240620 (2024), Gemini 1.5 Pro-002 (2024), Mistral Large-2407 / Nemo-2407 (2024).
- **검색·보조 모델**: 주요 통합기는 동일 LLM의 생성·검증 프롬프트. 별도 dense encoder 학습이 핵심이 아님.
- **검색 공간·방식**: 일반 QA: Google Search로 수집한 10 passages 제공; RGB는 부정 passage 5개 조건. 통합 과정 자체와 새 웹 탐색은 구별.
- **행동·종료·예산**: 내부 지식 생성 → 출처를 보존한 반복 통합 → 최종 답변.
- **추가 학습**: 주요 방법은 training-free, zero-shot 추론 절차.
- **근거 구성·실험 조작**: 검색 품질·정답 passage 비율, 부정 근거, 내부/외부 충돌을 비교.
- **지표·분모**: 정답 문자열 매칭 기반 accuracy; 데이터셋별 baseline 비교.
- **대표 결과·조건**: 부실 검색 조건을 포함해 일반 RAG 대비 개선 보고. 생성 passage를 단순 추가하는 것과 출처별 통합을 구분해 평가.
- **해석 포인트**: 내부 passage도 오류 가능. 우리 C0는 closed-book 비교 조건이며 사전 안정성 확인과도 구별. 생성 passage를 후속 입력에 넣는 Astute의 역할과 다름.
- **원문 확인 위치**: §4, §5.1–5.3, Appendix B

## D05 · Micro-Act · 2025 · arXiv v2

- **묶음**: 분해|충돌
- **연구 질문·Task**: 충돌을 작은 추론 단위로 나누면 해결할 수 있는가?
- **입력·평가 단위·정답 기준**: 질문 + 충돌 근거 → 선택형 정답. 내부 정보 호출·추론·분해·확정 행동.
- **데이터셋·표본**: ConflictBank (2024): 3종 충돌에서 3,000개; KRE (2023): MuSiQue (2022), SQuAD 2.0 (2018) 파생 2,000개.
- **주요 모델·역할**: GPT-4o / GPT-4o mini (2024), Llama 3.1 8B/70B (2024).
- **검색·보조 모델**: 주요 비교는 LLM의 생성·분해 행동; 별도 검색기 학습이 핵심이 아님.
- **검색 공간·방식**: 준비된 충돌 문맥에서 계층적 추론; ELICIT를 웹 검색으로 해석하지 않음.
- **행동·종료·예산**: ELICIT / REASON / ASSERT / DECOMPOSE; 분해 깊이·반복을 제한.
- **추가 학습**: ICL·프롬프팅 기반 추론 비교; 주 LLM 추가 학습 없음.
- **근거 구성·실험 조작**: 오정보·시간·의미 충돌; 행동 제거·모델 변경·문제 복잡도 비교.
- **지표·분모**: 선택형 QA accuracy; 행동·오류 분석.
- **대표 결과·조건**: 충돌 해소 성능 개선을 보고하며, 불필요한 분해와 과잉 합리화도 분석.
- **해석 포인트**: 두 설명을 그럴듯하게 양립시키는 것과 실제 사실을 검증하는 것은 별개.
- **원문 확인 위치**: §6–7, 주 결과표와 ablation

## D06 · CRITIC · 2024 · ICLR

- **묶음**: 교정
- **연구 질문·Task**: 외부 도구 피드백이 자기 비평과 답 수정에 도움이 되는가?
- **입력·평가 단위·정답 기준**: 초기 답 + 도구 관찰 + 비평 → 수정 답. 여기서는 QA 실험 중심.
- **데이터셋·표본**: AmbigNQ (2020), TriviaQA (2017), HotpotQA (2018): validation 각 500개. 수학·독성 과제는 별도 실험.
- **주요 모델·역할**: GPT-3.5-Turbo (2023), text-davinci-003 (2022), Llama 2 7B/13B/70B (2023).
- **검색·보조 모델**: QA는 웹 검색 도구; 다른 과제는 코드 실행/독성 평가 도구로 외부 피드백 종류가 달라짐.
- **검색 공간·방식**: QA에서는 웹 검색 및 캐시 사용. 문맥을 재독하는 것과 외부 관찰을 구별.
- **행동·종료·예산**: QA 수정 최대 3회; 연속 수정 답이 같으면 조기 종료. 도구 상호작용 한도 별도.
- **추가 학습**: 추가 데이터·주 LLM 학습 없이 프롬프팅.
- **근거 구성·실험 조작**: 도구 포함/제거, 초기 추론 방식, oracle 수정 조건 비교.
- **지표·분모**: QA EM·token F1; 다른 과제의 정확도·독성 점수와 분리.
- **대표 결과·조건**: QA에서 도구 기반 수정이 도구 없는 자기 수정 대비 유리. 원문 Table 1의 CRITIC*는 오답만 수정하는 oracle 조건.
- **해석 포인트**: 별표 결과를 일반 시스템 성능으로 발표하지 않기. 외부 피드백은 항상 웹 문서를 뜻하지 않음.
- **원문 확인 위치**: §3, §4.1, Table 1, Appendix F

- **행동·종료·예산**: 공격자는 planner/executor로 분해 질문을 예상; victim은 원 시스템 절차 사용.
- **추가 학습**: LLM prompting 기반 공격; 주 LLM 추가 학습이 핵심 아님.
- **근거 구성·실험 조작**: poisoning budget·attack 구성요소·방어·retriever 변경; 근거당 30단어 제한.
- **지표·분모**: ASR = 목표 반대 판정 유도 비율; SFR = 어떠한 잘못된 판정이든 유도한 비율. 분모는 표적 subset.
- **대표 결과·조건**: baseline 공격 대비 더 높은 공격 효과를 보고; ASR과 NEI 등까지 포함하는 SFR을 분리.
- **해석 포인트**: ‘웹을 더 검색하면 항상 해결’이라고 할 수 없음. 추가 검색 경로 자체가 공격 대상이 될 수 있음.

## D29 · FreshLLMs · 2023 · preprint

- **묶음**: 시점
- **연구 질문·Task**: 최신·거짓 전제 질문을 검색 증거로 더 정확히 답할 수 있는가?
- **입력·평가 단위·정답 기준**: 자연어 질문 → 답; false-premise는 전제를 지적해야 정답.
- **데이터셋·표본**: FreshQA (2023): 사실 변동 속도·거짓 전제별 dynamic QA, 평가 당시 snapshot 기준.
- **주요 모델·역할**: GPT-4 (2023): FreshPrompt 주요 비교; GPT-3.5 계열 (2022/2023), PaLM (2022) 등 closed-book 비교.
- **검색·보조 모델**: Google Search에서 최신 결과와 관련 질문 등 수집; 핵심은 검색 증거의 prompt 구성.
- **검색 공간·방식**: 실제 웹 검색을 활용하되 고정된 증거 수집·프롬프트 구성과 자율 반복 정책을 구별.
- **행동·종료·예산**: 수집한 evidence 수·순서·프롬프트 예시·답변 지시 비교.
- **추가 학습**: 추가 학습 없이 few-shot prompting.
- **근거 구성·실험 조작**: 시간 변동성, false premise, 검색 수·배치 순서.
- **지표·분모**: Relaxed: 주 답 정확성; Strict: 추가 설명의 사실성까지 포함. 둘 다 사람 평가 기준 명시.
- **대표 결과·조건**: FreshPrompt가 자료 없는 GPT-4 대비 크게 개선; relaxed/strict 차이는 부연 설명의 오류를 드러냄.
- **해석 포인트**: 모델 공개 연도는 knowledge cutoff가 아님. 동일 FreshQA라도 평가 날짜가 다르면 정답이 바뀔 수 있음.

## D30 · ClaimDecomp · 2022 · EMNLP

- **묶음**: 분해
- **연구 질문·Task**: 복합 주장 검증에 필요한 명시·암묵적 질문을 생성할 수 있는가?
- **입력·평가 단위·정답 기준**: claim + 발언 맥락 → yes/no subquestions. 검증 대상은 질문의 포괄성·유용성, 일부 downstream 판정.
- **데이터셋·표본**: ClaimDecomp (2022): 1,200 unique claims, train 800 / val 200 / test 200; 주석자는 justification에 접근.
- **주요 모델·역할**: T5-3B (2019 최초 공개/2020 학회): 하위 질문 생성.
- **검색·보조 모델**: 검색 실험에서 생성한 질문을 query로 사용; 생성 평가와 검색 평가를 구별.
- **검색 공간·방식**: 분해 질문의 근거 검색 기여 평가. gold 제작의 justification은 test-time 모델 입력이 아님.
- **행동·종료·예산**: QG-MULTIPLE과 QG-NUCLEUS, literal/implied 질문 비교.
- **추가 학습**: 있음: T5 question generator 지도 fine-tuning.
- **근거 구성·실험 조작**: 입력에 justification을 주는 분석 조건, 생성 전략·질문 유형 비교.
- **지표·분모**: 사람 기준 질문 recall(전체/literal/implied), 유용성 점수; downstream retrieval 별도.
- **대표 결과·조건**: Validation-sub: QG-MULTIPLE recall 전체 .58, literal .74, implied .18 (Table 3).
- **해석 포인트**: 이 .58은 fact-checking accuracy가 아님. 질문 생성 수를 사람이 정한 수에 맞춘 설정도 고려.

## D31 · Decomposition Dilemmas · 2025 · paper version

- **묶음**: 분해
- **연구 질문·Task**: 주장 분해가 검증을 돕는 조건과 오히려 해치는 조건은 무엇인가?
- **입력·평가 단위·정답 기준**: claim/긴 response → subclaims → retrieval → entailment → harmonic mean 집계.
- **데이터셋·표본**: WICE (2023) test 382건, ClaimDecomp (2022) dev/test 400건: claim-level. FELM (2023) WK 184건, BingChat (2024, 논문 인용 데이터) 396건: response-level.
- **주요 모델·역할**: GPT-4o mini (2024): 기본 분해·일부 판정; GPT-4o (2024): 분해 오류 진단·수정.
- **검색·보조 모델**: AlignScore (2023), Bespoke-MiniCheck-7B (2024): verifier. stella_en_400M_v5 (2024): WICE용 embedding; Chroma DB 사용.
- **검색 공간·방식**: WICE는 Wikipedia top-3 articles; 나머지는 Google/Serper top-10 results.
- **행동·종료·예산**: 분해→검색→판정→집계의 고정 workflow; 분해문 수정 실험 별도.
- **추가 학습**: 주요 비교는 기존 모델·프롬프트·분해 방식; verifier의 사전 학습과 이번 연구의 추가 학습을 구별.
- **근거 구성·실험 조작**: 분해 방법·검증기·입력 단위·복잡도·분해 오류 수정 비교.
- **지표·분모**: Balanced Accuracy·F1, 평균 subclaims 수. 최종 집계 단위로 점수 산출.
- **대표 결과·조건**: WICE/MiniCheck 예: 원문 BAcc 80.01, FactScore 분해 71.11; 평균 subclaims 3.91.
- **해석 포인트**: 더 세밀한 분해가 항상 좋은 것은 아님. 검색 잡음·의미 누락·집계 방식이 함께 작용.
