# 발표 논문 읽기 지도 — 15개 주제, 32편

기존 **31편 통합 가이드**를 유지하고, 그 뒤에 나온 개별 해설과 이번에 보강한 **RAGuard·Stop-RAG**를 연결했습니다. 32는 이번 발표에 실제 포함된 서로 다른 논문 수입니다. 기존 31편에서 모두를 사용한 것은 아니며, 중복 등장하는 Ev2R·HAE-GEO는 한 번만 셉니다.

[팀 논의와 Task](팀논의_연구방향과_Task.md) · [발표 PPTX](NLP_Team5_Midterm_18slides.pptx)

## 먼저 읽을 경로

- 연구 질문: Real Documents → VitaminC → Flip Risk → RAGuard → CRAG.
- Agent 행동: ReAct → FIRE → BeliefRAG → Stop-RAG.
- 자료와 평가: FEVER/AVeriTeC → ALCE/Ev2R → Dated Data → Evidence Laundering.
