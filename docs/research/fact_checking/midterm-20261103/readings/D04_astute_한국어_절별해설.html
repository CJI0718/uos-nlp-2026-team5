먼저 붙잡을 질문

검색한 문서가 모두 틀렸을 때 생성한 내부 문서는 어떤 역할을 하나요?

왜 선택했나 — 출처를 보존하며 내부·외부 정보를 통합하는 직접 선행연구. 검색 결과가 불완전할 때 외부 정보만 믿거나 모델의 기억만 믿는 선택을 넘어, 두 정보원에서 유효한 내용을 모아 답하려는 연구다. 우리 상태표의 출처 구분을 설명할 때 반드시 비교해야 한다.

논문의 논증을 먼저 따라가기

출발점은 검색 문서의 품질을 바꾸면 같은 모델의 답이 어떻게 달라지는지 관찰하는 실험이다. 저자들은 정답을 직접 포함하는 passage의 비율과 지식 충돌을 비교한다. 정밀도가 낮아질수록 충돌이 대체로 늘지만 0%에서는 다시 줄기도 한다. 관련 없는 텍스트만으로는 모델이 믿을 만한 대안 자체가 만들어지지 않을 수 있기 때문이다. 조사한 충돌 사례에서는 내부 정보가 맞는 경우와 외부 정보가 맞는 경우가 모두 상당했다.

그래서 §4는 두 정보원 모두에 기회를 주는 세 단계로 이어진다. 먼저 모델이 질문에 관련된 내부 passage를 생성한다. 다음으로 생성된 passage와 검색 passage의 기원을 구분한 채 서로 일치하거나 충돌하는 정보를 반복적으로 모은다. 마지막으로 그룹별 답 후보와 지지 문서를 비교해 답을 확정한다. Figure 4는 입력에서 답까지의 지도이고 Algorithm 1은 어느 과정이 반복되는지 보여준다.

§5에서는 Gemini·Claude 계열에서 자료 없는 답, 일반 RAG, 강건성을 높인 기존 RAG 방법들과 비교한다. 저자들은 검색 상황이 나쁜 조건까지 포함해 개선을 보고한다. 이 비교가 알려주는 것은 이미 들어온 근거를 더 잘 통합하는 효과다. 우리 설계에서 다음 검색까지 추가한다면 ‘처음 문서의 통합이 개선되었는가’와 ‘새로 읽은 자료가 결정적이었는가’를 로그에서 구별할 이유가 생긴다.

모델에 관련 정보를 passage 형태로 생성시킨 뒤 이를 후속 입력에서 참조할 수 있게 합니다. 이 문서는 가중치 내부를 직접 읽은 결과가 아니라 관찰 가능한 생성 텍스트입니다. 다음 단계에 포함되기 때문에 내용과 출처 유형을 명시적으로 비교할 수 있습니다.

§4.3–4.4 · 출처를 보존하며 통합하고 답하기

PDF pp. 5–6

생성한 자료와 검색한 자료의 출처를 구별한 채 일치와 충돌을 정리하고, 통합된 내용을 토대로 답을 만듭니다. 서로 다른 텍스트를 길게 이어 붙이는 것과 달리 무엇이 어디에서 왔는지 모델에 알려 줍니다. 내부 passage가 자동으로 정답 취급되는 절차는 아닙니다.

§§5–6 · 왜 우리 C0와 구별해야 할까요?

PDF pp. 6–9

여러 검색 품질·모델에서 QA 성능을 비교하고 구성요소의 기여를 해석합니다. 우리는 자료 없는 응답으로 평가 사례의 출발 상태를 진단합니다. 그 응답을 추가 passage로 C1에 주는 것은 별도 처치입니다. 두 단계가 다르다는 점을 발표에서 명시하면 내부 지식의 의미가 정확해집니다.

논문 결과와 우리 설계의 경계

원문에서 보고한 결과. 논문은 여러 검색 품질 조건에서 기존 방식보다 좋은 QA 성능을 보고하고, 검색 결과가 모두 도움이 되지 않는 조건에서도 closed-book 성능을 유지하거나 넘는 결과를 제시한다.

우리 연구로 가져올 부분. 출처를 구분하는 상태표는 선행연구에서 이어받은 원칙으로 소개한다. 우리의 질문은 그 상태를 이용해 어떤 원문을 추가로 확인할지 선택하면 교정/보존과 비용이 어떻게 달라지는가다. 공정한 비교에는 검색 이후 통합만 강화한 조건도 유용할 수 있다.

팀에서 풀어 볼 질문. 자료 없는 답을 저장해 C0 진단에만 사용하는 것과, 그것을 passage로 다시 C1에 주는 것 중 어느 쪽이 원 논문의 사용법에 더 가까운가요?

Astute RAG의 “내부 지식 passage”는 CoT와 어떻게 다른가요?

30초 답변: “모델이 생성한 지식을 후속 단계에서 실제로 읽는 passage로 외부화한다는 점이 핵심입니다. 학습된 가중치를 직접 읽는 것이 아닙니다.”

풀어서 설명: Adaptive passage generation으로 내부 지식 텍스트를 만들고, 검색 문서와 함께 출처를 보존해 반복적으로 통합합니다. Figure 4에는 관련 없거나 서로 일치·충돌하는 지식을 구분하고 최종 후보를 고르는 과정이 있습니다. 모델 내부 attention을 쓴다는 공통 원리만으로 CoT와 같은 실험이라고 볼 수는 없습니다. 어떤 텍스트를 만들고 어디에 다시 넣고 어떻게 채택하는지가 다릅니다.

연구 연결: 우리의 closed-book 사전 점검이 데이터 선정에만 쓰이고 본 실험에 주입되지 않는다면, Astute RAG의 내부 passage 활용과 구별됩니다.
