# 팩트체크 에이전트는 언제 판단을 고쳐야 할까요?

같은 설립 연도를 인용한 기사 세 편이 하나의 보도자료를 반복한다면, 에이전트는 어디를 더 확인해야 할까요? 5조는 실제 게시물 50건에서 출발해 같은 초기 판정을 고정 검증, 일반 ReAct, 근거 상태표를 쓰는 ReAct에 주는 비교를 제안합니다. 세 방법이 오답을 얼마나 고치고 정답을 얼마나 보존하는지, 그 판단을 어떤 근거로 뒷받침하는지 살펴봅니다.
