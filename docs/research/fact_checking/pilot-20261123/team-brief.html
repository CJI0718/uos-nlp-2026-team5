4. 무엇을 주장할 수 있나요?

관찰. 두 모델 모두 ‘목표’가 등장하면 적어도 일부 실행에서 목표치를 먼저 찾았고, ‘초과’ 문장에서는 잘못된 초기 자료만으로 멈췄습니다. 검색을 했다는 사실 하나로는 모델이 기존 수치에 의문을 품었다고 볼 수 없습니다. 검색 전의 질의가 빠진 목표치를 묻는지, 이미 주어진 실적을 재확인하는지 구별할 수는 있습니다.

최정일 개인 가설. 충분한 반대 증거를 나중에 동일하게 받더라도, 이미 잘못된 수치를 읽은 조건에서 그 수치를 최종 판정의 근거로 다시 채택할 가능성이 높을 수 있습니다. 여기서 ‘잔여 정보’는 측정할 행동에 붙인 이름입니다. 354만을 언급하면서 명시적으로 기각한 응답은 성공 사례입니다. Opus의 기각과 선행 gpt-oss의 정정은 두 모델 모두 그 행동을 할 수 있다는 실례입니다.

해석 범위. 현재 44회는 사건 하나의 반복입니다. Opus는 조건당 1회이고, D2 노출은 모델이 검색했는지에 달려 있었습니다. 따라서 두 모델의 일반적 우열, 어텐션의 인과적 한계, 웹의 평균 개선 효과, 인간 대비 성능, 별도 학습이나 사람 개입의 필요성을 이 표로 확정할 수 없습니다. 늦은 기사 날짜, 출처 표현, 검색 예산 소진, 질의에 포함된 숫자도 대안 설명입니다. 도구 호출·반환 자료·최종 답변에서 확인할 수 있는 행동을 근거로 삼습니다.

실행마다 독립 세션을 쓰고 두 조건의 선행 문서 길이·출처 표기·기사일·문체·수치 위치를 가능한 한 맞춥니다. 모델·공급자·샘플링 설정을 고정하고 실행 순서를 교차합니다. 핵심 지표는 오도 수치 채택률 차이입니다. 조건별 채택률은 ‘354만을 최종 판단의 사실로 사용한 횟수 / 유효 응답 수’이고, Δ채택률 = B1 채택률 − B0 채택률입니다. 가령 가상의 B1이 4/10, B0가 1/10이면 +30%p입니다. 유효 응답과 전체 시도·실패 수를 함께 보고합니다.

채점자는 최종 판정, 채택 수치와 인용 근거를 각각 표시합니다. ‘354만은 잘못이며 실제는 254만 831명’은 명시적 기각, 정확한 수치와 판정만 제시하면 정답·기각 언급 없음, ‘354만이므로 초과’는 오도 채택입니다. 보류와 기타 오류·자기모순도 구분합니다. ‘반박’이라는 라벨이 맞아도 잘못된 이유를 대면 근거 충족 점수를 주지 않습니다. B0에서 모델이 스스로 354만을 말할 가능성도 같은 기준으로 기록합니다.

A · 무엇이 추가 검증을 시작하게 하는가?

같은 ‘목표 달성’ 주장과 동일한 오도 실적 354만을 제공합니다. A1은 자료에서 목표 관람객 수를 생략하고, A2에는 검증된 목표 300만 명을 한 문장으로 넣습니다. 두 입력의 길이·출처·배치를 맞추고, 검색 권한·도구 예산은 동일하게 둡니다. 첫 행동 전까지는 D2를 주지 않습니다. 모델에 질문 분해를 요구하지 않고 자발적으로 고른 첫 행동을 관찰합니다.

검색 결과가 들어오기 전에 작성한 질의를 목표 / 실적 / 둘 다 / 기타로 코딩하고 즉시 종료도 셉니다. 한 턴에 여러 질의를 내면 첫 질의와 같은 턴의 전체 질의를 둘 다 남깁니다. 검색 개시율 = 첫 관찰 전에 검색을 시도한 실행 수 / 전체 유효 실행 수입니다. 실적 재확인율 = 첫 검색 묶음에 실적을 묻는 질의가 있는 실행 수 / 전체 유효 실행 수이고, 검색한 실행만을 분모로 쓴 비율도 병기합니다. 예를 들어 ‘행사 목표 관람객’은 목표만, ‘폐막 최종 관람객’은 실적입니다. 이 구분으로 빠진 정보를 메운 행동과 주어진 수치를 교차검증한 행동을 나눕니다.
