# 팩트체크 Agent 추가 문헌 56편

[연구 지도와 실험 선택 안내](./팩트체크_연구지도.md) · [Liner 회수 기록](./Liner_문헌표_회수기록.md) · [구조화 문헌 목록](./papers.json)

제공된 DOCX의 핵심 25편·확장 4편 및 기존 팀 저장소의 35개 학술 자료와 구별한 **추가 56편**이다. 같은 논문의 arXiv·학회판·PDF는 한 편으로 계산했다. E 번호는 이 문서의 식별자이며 기존 저장소의 FC 번호, DOCX의 P 번호와 다르다.

## 읽는 법

- **논문에서 확인**: 공식 학회/출판사 페이지 또는 저자 arXiv 초록·서지에서 확인한 내용. 일부 검색 결과에는 본문 발췌도 있으나, 아래 전부를 전문 정독한 것은 아니다.
- **우리 활용·비교 metric·비용/주의**: 우리 팀에 맞춘 제안과 해석이다. 논문 저자가 그 실험을 했다는 뜻이 아니다. 특히 각 카드의 metric 목록은 **우리 실험용 후보**이며 원 논문의 전체 공식 metric을 복제한 목록이 아니다.
- **비용**은 소규모 subset·기존 checkpoint 이용을 가정한 상대 부담이다. 금액/GPU 시간/재현 성능은 측정하지 않았다. API·GPU 실험, 데이터셋 다운로드·학습은 이번 작업에서 하지 않았다.
- arXiv 확인만으로 동료심사를 가정하지 않았다. 일부 항목의 학회 상태는 추가 확인 대상으로 남겼다. 제목과 최초 공개 연도, 정식 출판 연도가 다르면 구별했다.
- 코드/데이터가 공개되어 있어도 라이선스·뉴스 원문/이미지 권리·모델 라이선스가 같다는 뜻은 아니다. 실행·재배포 전에 개별 확인한다.

## 1. 주장 추출·선별·분해

<a id="e01"></a>

### E01 · Towards Effective Extraction and Evaluation of Factual Claims (Claimify)

**Metropolitansky & Larson · ACL 2025** · [원문](https://aclanthology.org/2025.acl-long.348/)
발굴 경로: Exa · 확인 수준: B: 원문 초록·서지 확인; 전문 정독 아님

- **논문에서 확인:** 모호성을 처리하면서 검증 가능한 주장을 추출하고, coverage·decontextualization을 포함한 추출 평가 체계를 제시한다.
- **자료/태스크:** 장문 생성물의 주장 추출·평가. 원시 데이터의 재사용 조건은 추가 확인.
- **우리 활용:** 문장 전체를 곧바로 검증하는 방식과 Claimify식 선별·분해를 비교한다.
- **비교 metric 후보:** 주장 coverage, 원문 entailment, 문맥 독립성, 최종 판정 Macro-F1.
- **예상 부담:** 중간: 여러 추출 단계와 사람 검수. **주의:** 추출기가 원문에 없던 정보를 보태면 이후 검증 점수도 왜곡된다.

<a id="e02"></a>

### E02 · Claim Extraction for Fact-Checking: Data, Models, and Automated Metrics

**Ullrich et al. · arXiv 2025; 학회 게재 여부 미확인** · [원문](https://arxiv.org/abs/2502.04955)
발굴 경로: Exa · 확인 수준: B: 원문 초록·서지 확인; 전문 정독 아님

- **논문에서 확인:** FEVERFact와 atomicity·fluency·decontextualization·faithfulness·focus·coverage 평가 틀을 제시한다.
- **자료/태스크:** FEVER 기반 contextualised Wikipedia 문장과 원자 주장.
- **우리 활용:** 한국어 분해 결과의 평가표를 만들 때 단순 문장 수 대신 여섯 품질 축을 사용한다.
- **비교 metric 후보:** 각 추출 품질 점수, 인간 평가와 일치도, 최종 오류 전파율.
- **예상 부담:** 중간: 평가기 및 소규모 사람 평가. **주의:** 자동 metric과 gold 문장 매칭을 한국어에서 별도 검증해야 한다.

<a id="e03"></a>

### E03 · ClaimRank: Detecting Check-Worthy Claims in Arabic and English

**Jaradat et al. · NAACL 2018 System Demonstrations** · [원문](https://aclanthology.org/N18-5006/)
발굴 경로: Exa · 확인 수준: B: 원문 초록·서지 확인; 전문 정독 아님

- **논문에서 확인:** 팩트체커가 먼저 확인할 주장을 순위화하는 시스템이다.
- **자료/태스크:** 정치 토론과 여러 팩트체크 기관의 선택 기록; 아랍어·영어.
- **우리 활용:** RSS 기사에서 검증할 주장 우선순위를 정하는 앞단 baseline.
- **비교 metric 후보:** Precision@k, Recall@k, 검증 예산 내 중요 주장 coverage.
- **예상 부담:** 낮음~중간: 선택기만 먼저 비교 가능. **주의:** 검증 필요성은 참·거짓과 다르며 기관의 관심 편향도 반영한다.

<a id="e04"></a>

### E04 · A Closer Look at Claim Decomposition

**Wanner et al. · *SEM 2024** · [원문](https://aclanthology.org/2024.starsem-1.13/)
발굴 경로: Liner → Exa 원문 확인 · 확인 수준: B: 원문 초록·서지 확인; 전문 정독 아님

- **논문에서 확인:** 분해 방식만 바꿔도 FActScore가 달라지는 문제를 분석하고 DecompScore를 제안한다.
- **자료/태스크:** 생성 텍스트를 여러 방식으로 분해해 참조 자료와 비교.
- **우리 활용:** 생성 모델 오류와 평가용 분해기 오류를 분리하는 실험 설계에 사용한다.
- **비교 metric 후보:** 원문이 지지하는 하위 주장 비율·수, 분해기별 최종 점수 변화.
- **예상 부담:** 낮음~중간: 분해 프롬프트 교체, 사람이 일부 재검수. **주의:** 서로 다른 분해기를 쓴 FActScore를 공정한 모델 순위로 간주하면 안 된다.

<a id="e05"></a>

### E05 · Decomposition Dilemmas: Does Claim Decomposition Boost or Burden Fact-Checking Performance?

**Hu et al. · NAACL 2025; 최초 preprint 2024** · [원문](https://arxiv.org/abs/2411.02400)
발굴 경로: Liner → Exa 원문 확인 · 확인 수준: B: 원문 초록·서지 확인; 전문 정독 아님

- **논문에서 확인:** 분해가 주는 이득과 새로 유입되는 잡음 사이의 상충을 분석한다.
- **자료/태스크:** Decompose-Then-Verify 파이프라인 오류 사례와 실험; 데이터별 세부 설정은 전문 확인 필요.
- **우리 활용:** 원문 검증·항상 분해·필요할 때 분해를 비교할 직접 근거.
- **비교 metric 후보:** 최종 Macro-F1, 원문 의미 손실률, 분해 후 정답→오답 변화율.
- **예상 부담:** 낮음~중간: 기존 파이프라인에 ablation 추가. **주의:** ‘원자화할수록 좋다’는 가정을 두지 않는다.

## 2. 대조쌍·편향·행동 진단

<a id="e06"></a>

### E06 · CrossAug: A Contrastive Data Augmentation Method for Debiasing Fact Verification Models

**Lee et al. · CIKM 2021 short paper** · [원문](https://arxiv.org/abs/2109.15107)
발굴 경로: Exa · 확인 수준: B: 원문 초록·서지 확인; 전문 정독 아님

- **논문에서 확인:** 주장·근거를 각각 변형한 뒤 원본과 교차 조합하는 2단계 증강으로 편향을 줄인다.
- **자료/태스크:** FEVER 및 편향을 줄인 확장 평가, 저자원 학습 설정.
- **우리 활용:** DOCX의 c0/c1 × e0/e1 구상과 매우 가까운 선행연구. 학습 증강과 우리의 평가용 대조쌍을 구분한다.
- **비교 metric 후보:** 네 조합 평균 정확도, 그룹 전체 정답률, 변형별 일관성.
- **예상 부담:** 평가만 하면 낮음~중간; 재학습은 중간~높음. **주의:** 교차 조합이라는 형식 자체를 새 기여로 주장하기 어렵다. 각 셀 라벨은 사람 검수 필수.

<a id="e07"></a>

### E07 · Annotation Artifacts in Natural Language Inference Data

**Gururangan et al. · NAACL 2018 short paper** · [원문](https://aclanthology.org/N18-2017/)
발굴 경로: Liner → Exa 원문 확인 · 확인 수준: B: 원문 초록·서지 확인; 전문 정독 아님

- **논문에서 확인:** 근거를 보지 않고 가설의 표현만으로 라벨을 예측할 수 있는 주석 편향을 보인다.
- **자료/태스크:** SNLI·MultiNLI.
- **우리 활용:** 부정어·어휘·길이만으로 합성/라벨이 드러나는지 진단한다.
- **비교 metric 후보:** claim-only 정확도, 다수 클래스 대비 차이, 변형 유형별 오차.
- **예상 부담:** 낮음: 간단한 분류기 또는 제한 입력 baseline. **주의:** NLI에서의 결과를 현재 한국어 LLM의 편향 정도로 직접 환산할 수 없다.

<a id="e08"></a>

### E08 · Hypothesis Only Baselines in Natural Language Inference

**Poliak et al. · *SEM 2018** · [원문](https://aclanthology.org/S18-2023/)
발굴 경로: Liner → Exa 원문 확인 · 확인 수준: B: 원문 초록·서지 확인; 전문 정독 아님

- **논문에서 확인:** 여러 NLI 데이터에서 가설만 사용하는 baseline을 진단 도구로 제안한다.
- **자료/태스크:** 10개 NLI 데이터셋.
- **우리 활용:** claim-only·evidence-only·전체 입력을 함께 보고 부분 입력 shortcut을 찾는다.
- **비교 metric 후보:** 부분 입력 정확도, full-input 대비 차이.
- **예상 부담:** 낮음. **주의:** 부분 입력 모델의 실패만으로 편향이 없다고 증명할 수 없다. 무근거 LLM의 지식 기억 효과와도 구분한다.

<a id="e09"></a>

### E09 · Counterfactual Debiasing for Fact Verification (CLEVER)

**Xu et al. · ACL 2023** · [원문](https://aclanthology.org/2023.acl-long.374/)
발굴 경로: Liner → Exa 원문 확인 · 확인 수준: B: 원문 초록·서지 확인; 전문 정독 아님

- **논문에서 확인:** claim-evidence 모델과 claim-only 모델을 따로 학습한 후 출력을 보정한다.
- **자료/태스크:** FEVER 계열·다중 hop·MultiFC 설정.
- **우리 활용:** 평가용 대조쌍에서 끝나지 않고 판정 모듈의 편향을 보정하는 확장 후보.
- **비교 metric 후보:** 편향 subset 정확도, 원래 분포 성능, 보정 전후 격차.
- **예상 부담:** 중간~높음: 두 모델 학습·점수 접근. **주의:** API의 자연어 답변 두 개를 빼는 방법이 아니다. 논문의 출력·학습 정의를 따라야 한다.

<a id="e10"></a>

### E10 · FaVIQ: FAct Verification from Information-seeking Questions

**Park et al. · ACL 2022; 최초 preprint 2021** · [원문](https://aclanthology.org/2022.acl-long.354/)
발굴 경로: Liner → Exa 원문 확인 · 확인 수준: B: 원문 초록·서지 확인; 전문 정독 아님

- **논문에서 확인:** 모호한 질문과 그 해소 결과에서 타당·부당 QA 조합을 만들고 주장으로 변환한다.
- **자료/태스크:** Natural Questions·AmbigQA 기반, Wikipedia 근거.
- **우리 활용:** 단순 부정어 삽입 대신 사건·인물·촬영/개봉 시점 혼동을 이용한 대조쌍 설계.
- **비교 metric 후보:** 대조쌍 정확도, 엔티티·시간 혼동별 성능.
- **예상 부담:** 중간: 질문→주장 변환 검수. **주의:** 질문과 답이 틀리게 연결된 경우가 모두 단순 REFUTE가 되는지 검수해야 한다.

<a id="e11"></a>

### E11 · Beyond Accuracy: Behavioral Testing of NLP Models with CheckList

**Ribeiro et al. · ACL 2020** · [원문](https://aclanthology.org/2020.acl-main.442/)
발굴 경로: Exa · 확인 수준: B: 원문 초록·서지 확인; 전문 정독 아님

- **논문에서 확인:** 능력별·검사 유형별로 NLP 모델의 행동을 진단한다.
- **자료/태스크:** 여러 NLP 태스크의 행동 테스트.
- **우리 활용:** 숫자 변경은 정답 전환, 동의어·문장 순서 변경은 불변성 등 서로 다른 검사를 설계한다.
- **비교 metric 후보:** 불변성 위반률, 방향성 위반률, 최소 기능 검사 실패율.
- **예상 부담:** 낮음: 작은 검수용 변형 세트. **주의:** 변형이 의미를 유지한다는 가정을 반드시 검토한다.

## 3. 근거 검색·표현·재순위화

<a id="e12"></a>

### E12 · BEIR: A Heterogenous Benchmark for Zero-shot Evaluation of Information Retrieval Models

**Thakur et al. · NeurIPS 2021 Datasets and Benchmarks** · [원문](https://arxiv.org/abs/2104.08663)
발굴 경로: Exa + Liner · 확인 수준: B: 원문 초록·서지 확인; 전문 정독 아님

- **논문에서 확인:** 여러 도메인의 lexical·sparse·dense·late interaction·reranking을 비교하는 retrieval benchmark다.
- **자료/태스크:** 18개 데이터셋. FEVER·Climate-FEVER·SciFact 등 사실검증 관련 태스크도 포함.
