## 1. 한 사례로 보는 실험

**주장(FC041, 2025-10-11 게시):** "소니의 PlayStation 6는 2027년에 출시된다." 정답은 **근거 부족**이에요. 게시 시점까지 소니는 연도를 발표하지 않았고, 2027년은 유출자의 말이에요.

| 조건 | 에이전트가 쓸 수 있는 것 | baseline 판정 | 개선 후 판정 |
| --- | --- | --- | --- |
| C0 | 도구 없음 | 근거 부족 ✅ | 근거 부족 ✅ |
| C1 | 고정 문서 78개 검색·열람 | **반박** ❌ "예측을 확정 사실로 단정했다" | 근거 부족 ✅ |
| C2 | C1 + 웹 검색(Tavily) | **반박** ❌ | 근거 부족 ✅ |

baseline 에이전트는 근거 문서(소니 설계 책임자의 "multi-year" 발언 보도)를 제대로 찾아 읽었어요. 그런데도 "전망을 사실처럼 썼으니 틀렸다"며 반박했어요. 오류 분석에서 이런 사례가 C1·C2 오류 13개 중 9개였고, Skill 규칙 하나를 고쳐 이 유형의 오답 대부분을 바로잡았어요(§4~§6).

## 3. baseline 결과 (exp-005)

150개 에피소드 모두 정상 종료했어요. 항상 "지지"라고 답하면 정확도는 60%예요.

| 조건 | 정확도 | Macro-F1 | 근거 동반 정답(자동) | 지지 재현율 | 반박 재현율 | 근거 부족 재현율 | 비용 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| C0 | 11/50 (22%) | 0.200 | 6/50 | 4/30 | 1/14 | 6/6 | $0.06 |
| C1 | 43/50 (86%) | 0.679 | 43/50 | 28/30 | **14/14** | **1/6** | $0.75 |
| C2 | 44/50 (88%) | 0.614 | 42/50 | **30/30** | **14/14** | **0/6** | $0.81 |

- **도구의 효과가 커요.** C0는 50개 중 43개를 "근거 부족"으로 답했어요(2025~26년 사건이라 모델이 모름). C0→C1에서 39개 오답 중 37개가 회복됐어요.
- **웹 검색은 거의 더하지 못했어요.** C1→C2 회복 2/7, 손상 1/43. 고정 코퍼스에 근거가 이미 있어서예요.
- **약점은 근거 부족 하나예요.** 반박은 변형 주장 8개와 실제 오류 6개 모두 맞혔지만, 근거 부족 6개는 C1 1개, C2 0개만 맞혔어요.

## 4. 오류 분석

C1·C2의 오답 13개를 대화 기록으로 하나씩 확인해 원인별로 나눴어요.

| 오류 유형 | 개수 | 사례 | 원인 |
| --- | ---: | --- | --- |
| 예측 주장을 **반박** | 9 | C1: FC003·017·026·038·041 / C2: FC003·026·038·041 | 근거를 읽고도 "전망을 사실처럼 썼다"며 반박. Skill의 왜곡 유형 목록에 `forecast_as_fact`가 있지만, 그때 판정을 무엇으로 할지 규칙이 없었음 |
| 예측 주장을 **지지** | 2 | C2: FC010·017 | 애널리스트·블룸버그의 전망 보도를 주장의 근거로 인용("전망이 있다" ≠ "그렇게 된다") |
| 코퍼스 본문 누락 | 2 | C1: FC021·040 | 닌텐도 보도자료는 본문이 페이지 데이터(Next.js)에만 있고, GitHub 파일 페이지는 메뉴만 추출됨. 모델은 "문서에 값이 없다"고 정확히 판단함 |

정답 유형별로 보면 오답은 **가격·금액**(예상가)과 **날짜**(출시 연도, 충돌일)에 몰려 있었어요. 비율·배수 계산과 수량·단위 21개는 C1·C2 모두 전부 맞혔어요.

오답은 아니지만 비효율도 하나 있었어요. C1에서 쓸 수 없는 웹 도구가 목록에 보여, 도구 호출 239회 중 10회가 막힌 호출이었어요.

## 10. 범위·출처·유의사항

- **실행 횟수:** 조건마다 한 번씩 돌렸고, 개선 대상 8개만 한 번 더 돌렸어요. temperature 0이어도 추론 모델이라 결과가 조금씩 달라요. 하네스와 관계없는 C0에서도 3개가 바뀌었어요(2개 정답, 1개 오답). 1~2개 차이는 잡음으로 봐야 해요. C1·C2에서 고쳐진 11개는 모두 노린 오류 유형이라 잡음보다 커요.
- **개발·평가 분리:** Action Item은 같은 50개의 오류에서 찾았어요. 따로 떼어 둔 개발용 사례가 없어서, 개선 효과가 이 50개에 맞춰진 것일 수 있어요. AI-1은 사례가 아닌 일반 규칙이고 가상 예시만 썼지만, 다른 사례로 확인하지는 않았어요.
- **처치에 포함된 것:** AI-2 때문에 코퍼스를 다시 수집했어요. 바뀐 문서는 GitHub 파일 4개와 닌텐도 페이지 1개예요. 그 밖의 문서는 같은 URL·같은 본문이에요(본문이 바뀐 다른 문서 1개는 길이가 같은 고용노동부 페이지).
- **근거 동반 정답(자동):** 인용 근거가 참조 근거(같은 코퍼스 문서 또는 같은 URL)와 겹치는지로 계산한 근사치예요. 다른 출처로 맞게 입증한 경우를 놓치고, 시점·범위(T)는 채점하지 않아요. 사람 채점(GSR의 E·T)은 하지 않았어요.
- **라벨 경계:** FC026처럼 확률 전망을 다루는 주장은 정답 기준이 논쟁적일 수 있어요. 근거 부족 6개가 모두 예측 주장이라 AI-1의 효과가 크게 보여요.
- **변형 주장:** 재가공 게시물 8개는 모두 반박이고 URL이 없어요. 에이전트가 이를 단서로 쓸 수 있는데, C0에서 변형 8개를 하나도 맞히지 못해 이번 결과에서는 그런 지름길이 보이지 않았어요.
- **모델·가격:** 모델 ID와 도구 호출 지원은 Mistral API `/v1/models`로, 가격은 [Mistral 가격표](https://docs.mistral.ai/inference/pricing)(2026-11-25 확인)로 확인했어요. Claude 비교는 이번에 돌리지 않았어요.
- **원자료:** 대화 기록과 서버 로그는 원문이 들어 있어 `results/raw/`(Git 제외)에만 있어요. 공개 결과에는 판정·개수·비용만 남겼어요.
