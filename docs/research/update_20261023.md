상태: 팀 검토용 제안. 최종 주제·모델·예산 미선정, 실험 미실행.

## 범위

- 원격 main의 이전 PR #1 병합본을 기준으로 작업했다. 기존 36개 후보와 47개 자료를 보존했다.
- 적응적 업무 X1–X7과 RL·멀티모달 RL1–RL6을 추가했다.
- 통합: 8개 주제군, 49개 후보, 60개 자료(논문 58편·아이디어 1건·공식 문서 1건).
- “새 후보”는 모두 별개의 신규 연구 분야라는 뜻이 아니다. 기존 관심을 업무·독립 변수로 구체화한 것도 있다.

## 원자료와 HTML

- [candidates.json](candidates.json): 후보·관련 논문. 기존 ID 유지.
- [atlas_guide.json](atlas_guide.json): 주제별 개념·과정·가설·통제·토론 질문과 지표.

HTML: 전체 지도 → 배경 이론 → 후보 검색 → 최대 4개 비교 → 데이터·평가·비용 → 전체 논문 → 논의 노트 → 상세 리서치.
JavaScript·CSS·데이터는 내장되며 실행 시 외부 서비스에 요청하지 않는다. 외부 논문 링크를 누를 때만 온라인 자료로 이동한다. 선택·메모는 로컬 브라우저 저장이며 내보낸 Markdown을 PR·Issue로 공유한다. GitHub Pages는 설정하지 않았다.

## 문헌 확인 경계

추가 두 리서치에서 Exa 11회 검색, 결과 항목 60개(동일 논문 중복 포함)를 탐색했다. 게시 전 신규 논문 12편과 MiniGrid 공식 문서 1건의 페이지를 재확인했다. 신규 자료는 P47–P58·D01이며 각 항목에 확인일·수준·한계를 적었다.

기존 P01–P46·I01은 이전 조사 기록을 보존했다. 모든 전문 정독·최신 출판 상태 재검증·코드 감사·실험 재현을 완료했다는 뜻은 아니다. Curie·MemTxn·V-Retrver 등 preprint를 학회 채택 논문으로 임의 승격하지 않았다. 인접 논문의 결과를 우리 축소 구현의 성능으로 제시하지 않았다.

## 연구 설계 보완

- X1: 검색 질의와 튜닝 mission을 구분한다.
- X4: 고정 평가 문장 50개와 active-learning 선택 라운드를 구분한다.
- X5: 50개 기본 시나리오의 표현 쌍은 조건 입력 수가 2배다.
- RL: 평가 50개 외 학습 자료·상호작용, 학습 seed·캐시 비용이 필요하다.
- RL 정책 갱신과 프롬프트 수정·자기 성찰을 구분한다.
- MiniGrid의 기호 관찰과 RGB 관찰, oracle와 일반 정책의 정보량을 구분한다.
- 같은 executor·도구·예산, 강한 결정론적 기준선, gold 비노출 원칙을 유지한다.

## 팀이 아직 결정할 사항

1. 가장 궁금한 업무·실패와 주된 독립 변수 하나.
2. 평가 단위와 50개 정답 검수 가능성.
3. baseline과 개발/학습/시험 분리.
4. 모델·장비·호출 및 GPU 시간 예산.
5. 과목별 제출 요건과 동일 연구의 복수 과목 활용 허용 여부.
