# 실제 웹 사례 후보 (검토 전)

합성 사례(exp-002)에서는 Skill만으로 잘못된 등록이 0건이었습니다. 그래서 실제 웹에서도 그런지, 게이트가 필요한 어려운 사례가 있는지 보려고 실제 일정·가격 발표를 모았습니다.

**이 파일의 판정은 모두 제안입니다.** 사람이 원문을 확인하기 전에는 gold로 쓰지 않습니다. 기사 본문은 저작권 때문에 저장하지 않았고, URL과 직접 쓴 한 줄 요약만 적었습니다.

## 수집 방법

2026-11-20에 Tavily 검색 26회(basic, 1회당 1크레딧, 그중 3회는 `end_date`를 건 검색)로 찾고, 나온 페이지를 `LiveWebProvider.fetch`로 직접 받아 비교했습니다. 모델은 호출하지 않았습니다.
- 페이지 비교는 서버와 같은 코드(본문 추출 → 글자 8-gram 포함률 → 자동 출처군)를 썼습니다.
- 시점 제한 없이 검색한 23회의 결과 205건 출처 구성: SNS·커뮤니티 31%, 뉴스·기타 29%, 공식 13%, 위키 12%, 블로그 9%, 영상 6%. 발행일이 붙은 결과는 48%입니다.
- 뉴스만 찾는 Tavily 설정(`topic: news`)으로 8회 검색했지만, 한국어 기사는 거의 나오지 않았습니다.

## 관찰한 것

1. **같은 보도자료를 다시 쓴 기사는 본문 겹침으로 묶이지 않았습니다.** 삼성 AI 안경 기사 5개는 발행 시각이 삼성전자 보도자료와 같은 2026-11-12 23:00이었습니다. 그런데 이 기사들과 보도자료의 포함률은 0.05~0.27이고, 기사끼리는 0.03~0.14였습니다(기준 0.4). 받은 기사 10개 중 같은 출처군으로 묶인 것은 다음 날 나온 MBC 기사와 연합뉴스(0.62) 한 쌍뿐입니다.
   지금 자동 출처군 규칙으로는 이 기사들이 서로 독립된 출처로 잡힙니다. 위험한 쪽의 오류입니다.
2. **숫자는 기사끼리 일치했습니다.** 날짜(12월 10일)와 가격(65만~70만 원)은 대부분 같았고, 한 기사만 달랐습니다(아래 R1). 문장보다 숫자 비교가 같은 원문을 가려내는 데 더 나은 신호입니다.
3. **그대로 베낀 문서는 잘 잡았습니다.** 나무위키의 언팩 문단은 삼성전자 뉴스룸과 0.96으로 같은 출처군이 됐습니다. 같은 위키백과 문서를 다른 URL로 받은 경우도 1.00이었습니다.
4. **공식 문서를 못 읽는 경우가 있었습니다.** Rockstar 공지(R8)는 JavaScript로 그려져 본문이 0자였습니다. 한국닌텐도의 방송 시간 공지는 X(트위터)에만 있어 받을 수 없었고, 검색 결과 스니펫으로만 보였습니다.
5. **공식 발표 전에는 틀린 날짜가 여러 매체에 반복됐습니다.** 애플 초대장(10월 19일) 전 기사들은 소식통을 인용해 "10월 27일 발표"라고 썼습니다. 실제 행사는 10월 28일(PT)이었습니다. 언팩 초대장(7월 7~8일) 전에도 "7월 22일 런던 유력" 기사가 여럿 있었고, 시각은 없었습니다.
6. **시점 제한에 빈틈이 있습니다.** 검색에 `end_date`를 걸어도 발행일이 없는 결과는 남습니다. cutoff를 2026-03-20으로 둔 검색에서, WWDC 2026이 이미 "진행되었다"는 위키백과 스니펫이 나왔습니다.
7. **다른 해의 같은 행사가 섞입니다.** 나무위키 WWDC 문서에는 WWDC21의 "6월 8일 오전 2시" 일정이 있습니다. WWDC 2026의 한국시간 기조연설은 6월 9일 오전 2시입니다.

## 실험용 사례 (exp-003)

일정 등록 실험에는 한국시간 `HH:MM`이 있는 사례만 씁니다. 위 표의 R4·R5·R6·R7·R9에, 공식 발표 전 시점으로 둔 사례 2개를 더했습니다.

- 주장 문장과 `input_body`는 실제 페이지를 바탕으로 제가 쓴 것입니다. 원문이 실제로 그렇게 썼는지는 `gold_cases.jsonl`의 `claim_basis`에 적었습니다. RW06·RW10·RW11은 원문에 없는 한국시간 시각을 붙여 만든 주장입니다.
- [claims.jsonl](claims.jsonl)은 에이전트가 보는 주장이고, [gold_cases.jsonl](gold_cases.jsonl)은 채점용입니다. gold 행은 모두 `status: proposed`입니다.
- 등록하면 안 되는 사례가 2개뿐입니다. 실험 결과의 "금지 행동" 비율은 사례 2개 × 모델 3개 = 6세션으로 계산됩니다.
- 이미 지난 행사라서 모델이 학습으로 날짜를 알 수 있습니다. 모델마다 학습 시점이 다르고 정확히 공개되지 않았으므로, 늦은 행사(9~10월: RW07·RW09·RW11)와 이른 행사(5~7월)를 나눠 읽습니다.
